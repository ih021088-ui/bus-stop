# 7790 버스 혼잡도 - 프론트엔드

## 파일 구조
```
bus-stop/
├── frontend/
│   ├── index.html   ← 네이버 지도 기반 혼잡도 표시 페이지
│   └── README.md
└── server.py        ← FastAPI 예측 서버
```

---

## 구현된 기능
- 네이버 지도 위에 정류장 마커 표시 (색상으로 혼잡도 구분)
- 사이드바에 정류장별 예상 탑승 인원 + 혼잡도 배지
- 시간대 선택 드롭다운 (현재 시각 기준 자동 선택)
- 마커 / 카드 클릭 시 해당 정류장으로 지도 이동 및 팝업 표시
- 현재 시각 자동 표시 (1분마다 갱신)
- API 연결 실패 시 mock 데이터로 자동 폴백

## 백엔드(server.py) 연결 방법

`index.html` 내 `API_BASE_URL`을 실제 서버 주소로 변경:

```javascript
const API_BASE_URL = 'http://localhost:8000';  // → 실제 서버 주소로 교체
```

server.py 실행:
```bash
uvicorn server:app --host 0.0.0.0 --port 8000
```

API 응답 형식:
```json
{
  "date": "2026-05-11",
  "hour": 15,
  "direction": "depart",
  "weather": { "temp_avg": 14.2, "precip_mm": 0.2, ... },
  "stops": [
    { "stop": "효행초등학교정문", "boardings": 10.9, "congestion": "여유" },
    ...
  ]
}
```
